Components v1.0

14 个基础组件的完整状态定义。样式全部取自 tokens.css，本文件不含任何具体色值， 切换 data-theme 后组件自动跟随。修饰符用 --，状态用 is-， 组件本身不带外边距，间距交给使用方的布局决定。

按钮 Button

01

三种层级加一种危险操作。btn--primary 在同一个界面里只能出现一次，用来标记当前最主要的动作（例如「更新数据」）。改动即时生效的界面不必再设主按钮，用状态条表达即可。

输入框 Input

02

聚焦时边框转主色并叠 3px 淡光晕。带图标的输入用 field 包一层，错误态用 is-error。

复选框 Checkbox

03

原生 checkbox 隐藏，用 .box 自绘。勾选后加 3px 淡光晕，点击热区整行 30px。

分段控件 Segmented

04

用于平级的二到四个视图切换，凹槽底 + 选中块内阴影，比标签页更轻。

筛选片 Chip

05

指标筛选、维度切换。选中时圆点发光并转主色，作为唯一的"已激活"信号。

标签 Tag / Pill / Badge

06

Tag 是等宽小标签（文件名、代码），Pill 是带主色的策略标识，Badge 是计数。三者字号都低于 11px，只做信息补充，不承担强调。

表格 Table

07

表头吸顶且背景必须不透明。数值列右对齐 + 等宽 + tabular-nums，保证小数点纵向对齐。 正负值用 is-up / is-down（红涨绿跌）。比率类指标可用 cell-bar 在单元格底部画一条进度线，用 --v 传 0–100。

标签页 Tabs

11

用于底部多品种并行视图。选中态是 1.5px 主色下划线加轻微外发光，不加背景块。

导航项 Nav item

12

左侧模块导航。选中态由左侧 2px 竖条 + 横向渐隐底构成，不使用整块实色，避免和表格选中行混淆。一级导航只放产品模块；设计规范、设置这类参考与工具页放侧栏底部，用小号文字链接，不占一级菜单。
